## 1. 核心数据结构与状态管理

### 1.1 注册表的状态模型

**位置**: `altair/utils/plugin_registry.py:83-146`

每个 `PluginRegistry` 实例维护以下状态：

```python
class PluginRegistry(Generic[PluginT, R]):
    # 配置属性
    entry_point_group: str              # 入口点组名称，用于自动发现
    plugin_type: IsPlugin               # 类型检查函数（默认 callable）
    
    # 状态属性（核心）
    _active: Plugin[R] | None           # 当前活跃插件实例（单一！）
    _active_name: str                    # 当前活跃插件名称（单一！）
    _plugins: dict[str, PluginT]        # 已注册插件字典 {名称: 插件}
    _options: dict[str, Any]             # 当前活跃插件的选项
    _global_settings: dict[str, Any]     # 全局设置
```

**关键设计**：
- `_active` 和 `_active_name` 是**单一值**，不是列表
- 这从根本上决定了：**同一类型只能有一个活跃插件**

### 1.2 状态保存与恢复机制

**位置**: `altair/utils/plugin_registry.py:183-203`

```python
def _get_state(self) -> dict[str, Any]:
    """返回完整的状态快照"""
    return {
        "_active": self._active,
        "_active_name": self._active_name,
        "_plugins": self._plugins.copy(),
        "_options": self._options.copy(),
        "_global_settings": self._global_settings.copy(),
    }

def _set_state(self, state: dict[str, Any]) -> None:
    """恢复到指定状态"""
    assert set(state.keys()) == {
        "_active", "_active_name", "_plugins", "_options", "_global_settings"
    }
    for key, val in state.items():
        setattr(self, key, val)
```

**状态快照包含**：
- 活跃插件实例和名称
- 所有已注册插件
- 当前选项
- 全局设置

这是上下文管理器能够**完整恢复**的基础。

### 1.3 上下文管理器的工作原理

**位置**: `altair/utils/plugin_registry.py:52-80`

```python
class PluginEnabler(Generic[PluginT, R]):
    def __init__(
        self, registry: PluginRegistry[PluginT, R], name: str, **options: Any
    ) -> None:
        self.registry = registry
        self.name = name
        self.options = options
        
        # 步骤 1: 进入时保存当前完整状态
        self.original_state: dict[str, Any] = registry._get_state()
        
        # 步骤 2: 启用新插件（直接覆盖）
        self.registry._enable(name, **options)
    
    def __enter__(self) -> PluginEnabler[PluginT, R]:
        return self
    
    def __exit__(self, typ: type, value: Exception, traceback: TracebackType) -> None:
        # 步骤 3: 退出时恢复原始状态
        self.registry._set_state(self.original_state)
```

**关键证据**：
- `original_state` 是**完整的状态副本**
- `__exit__` 时**完全恢复**，没有任何合并逻辑

## 2. 同类插件：优先级规则详解

### 2.1 规则一：多次 `enable()` — 后调用覆盖先调用

#### 代码证据

**位置**: `altair/utils/plugin_registry.py:205-224`

```python
def _enable(self, name: str, **options) -> None:
    # ... 入口点加载逻辑 ...
    
    # 关键：直接赋值，无检查，无合并
    self._active_name = name    # 直接覆盖
    self._active = self._plugins[name]  # 直接覆盖
    
    # 处理选项
    for key in set(options.keys()) & set(self._global_settings.keys()):
        self._global_settings[key] = options.pop(key)
    self._options = options  # 直接覆盖，不是合并！
```

**注意**：`self._options = options` 是**直接赋值**，不是 `update()`！

#### 场景演示

```python
import altair as alt

# 初始状态
alt.renderers.active  # "default"

# 第一次 enable
alt.renderers.enable("html")
alt.renderers.active  # "html"

# 第二次 enable — 直接覆盖！
alt.renderers.enable("svg")
alt.renderers.active  # "svg"（html 被完全覆盖）

# 第三次 enable
alt.renderers.enable("png")
alt.renderers.active  # "png"（svg 被完全覆盖）
```

#### 选项覆盖演示

```python
# set_embed_options 内部调用 enable(None, embed_options=...)
alt.renderers.set_embed_options(actions=True, width=400)
alt.renderers.options  # {"embed_options": {"actions": True, "width": 400}}

# 再次调用 — 完全覆盖，不是合并！
alt.renderers.set_embed_options(height=500)
alt.renderers.options  # {"embed_options": {"height": 500}}
# 注意：actions 和 width 丢失了！
```

**代码证据**: `RendererRegistry.set_embed_options()`

**位置**: `altair/utils/display.py:104-116`

```python
def set_embed_options(self, ...) -> PluginEnabler:
    options: dict[str, ...] = {
        "defaultStyle": defaultStyle,
        "renderer": renderer,
        "width": width,
        # ...
    }
    kwargs.update({key: val for key, val in options.items() if val is not None})
    
    # 关键：传递给 enable 的是完整的 kwargs
    return self.enable(None, embed_options=kwargs)
```

而 `_enable` 中：
```python
self._options = options  # 直接赋值，不是合并！
```

### 2.2 规则二：上下文管理器 — 内层覆盖外层，退出恢复

#### 代码证据

**位置**: `altair/utils/plugin_registry.py:64-77`

```python
def __init__(self, ...):
    # 进入时保存状态
    self.original_state = registry._get_state()
    # 启用新插件
    self.registry._enable(name, **options)

def __exit__(self, ...):
    # 退出时恢复原始状态
    self.registry._set_state(self.original_state)
```

#### 嵌套场景演示

```python
import altair as alt

# 全局状态
alt.theme.enable("default")
alt.theme.active  # "default"

# 第一层上下文
with alt.theme.enable("dark"):
    alt.theme.active  # "dark"（覆盖 default）
    
    # 第二层上下文 — 嵌套覆盖
    with alt.theme.enable("quartz"):
        alt.theme.active  # "quartz"（覆盖 dark）
        
        # 第三层上下文
        with alt.theme.enable("opaque"):
            alt.theme.active  # "opaque"（覆盖 quartz）
        
        # 退出第三层：恢复 quartz
        alt.theme.active  # "quartz"
    
    # 退出第二层：恢复 dark
    alt.theme.active  # "dark"

# 退出第一层：恢复 default
alt.theme.active  # "default"
```

#### 状态栈示意

```
初始状态: [default]
                   
进入 with dark:    保存 [default] → 启用 dark → 状态 [dark]
                   
  进入 with quartz: 保存 [dark] → 启用 quartz → 状态 [quartz]
                     
    进入 with opaque: 保存 [quartz] → 启用 opaque → 状态 [opaque]
                       
    退出 opaque:      恢复 [quartz] ← 状态 [quartz]
                     
  退出 quartz:        恢复 [dark] ← 状态 [dark]
                   
退出 dark:          恢复 [default] ← 状态 [default]
```

### 2.3 规则三：多次 `register()` 同名 — 后注册覆盖先注册

#### 代码证据

**位置**: `altair/utils/plugin_registry.py:147-173`

```python
def register(self, name: str, value: PluginT | None) -> PluginT | None:
    if value is None:
        return self._plugins.pop(name, None)  # 注销
    elif self.plugin_type(value):
        self._plugins[name] = value  # 字典赋值，天然覆盖！
        return value
    else:
        raise TypeError(...)
```

**关键**：`self._plugins[name] = value` 是**普通字典赋值**，直接覆盖。

#### 场景演示

```python
import altair as alt

# 定义两个主题函数
def theme_v1():
    return {"config": {"view": {"width": 300}}}

def theme_v2():
    return {"config": {"view": {"width": 500}}}

# 第一次注册
alt.theme._themes.register("my_theme", theme_v1)
# _plugins["my_theme"] = theme_v1

# 第二次注册 — 直接覆盖！
alt.theme._themes.register("my_theme", theme_v2)
# _plugins["my_theme"] = theme_v2（v1 丢失）

# 验证
alt.theme.enable("my_theme")
func = alt.theme._themes.get()
func()  # {"config": {"view": {"width": 500}}} —— 是 v2！
```

### 2.4 规则四：显式注册 vs 入口点 — 显式注册优先

#### 代码证据

**位置**: `altair/utils/plugin_registry.py:206-219`

```python
def _enable(self, name: str, **options) -> None:
    # 关键检查：只有 _plugins 中不存在时，才查入口点
    if name not in self._plugins:
        try:
            (ep,) = (
                ep
                for ep in importlib_metadata_get(self.entry_point_group)
                if ep.name == name
            )
        except ValueError as err:
            raise NoSuchEntryPoint(...) from err
        
        # 加载后注册到 _plugins
        value = cast("PluginT", ep.load())
        self.register(name, value)
    
    # 设置活跃状态
    self._active_name = name
    self._active = self._plugins[name]
```

#### 场景演示

假设有一个外部包 `altair-extra-themes` 通过入口点注册了 `"fancy"` 主题：

```python
# 外部包的 setup.py 或 pyproject.toml
# [project.entry-points."altair.vegalite.v6.theme"]
# fancy = "altair_extra_themes:FancyTheme"
```

用户代码：

```python
import altair as alt

# 用户显式注册同名主题
def my_fancy_theme():
    return {"config": {"background": "#FF0000"}}  # 红色背景

alt.theme._themes.register("fancy", my_fancy_theme)

# 启用 "fancy"
alt.theme.enable("fancy")

# 由于 name in self._plugins 为 True
# 跳过入口点加载
# 使用用户显式注册的版本
```

#### `names()` 方法的行为

**位置**: `altair/utils/plugin_registry.py:175-181`

```python
def names(self) -> list[str]:
    """列出所有注册的插件名称"""
    exts = list(self._plugins.keys())                          # 显式注册的
    e_points = importlib_metadata_get(self.entry_point_group)  # 入口点的
    more_exts = [ep.name for ep in e_points]
    exts.extend(more_exts)
    return sorted(set(exts))  # 去重
```

`names()` 会显示两者的并集，但 `enable()` 时显式注册的优先。

## 3. 主题配置：合并机制深度分析

### 3.1 主题合并的核心代码

**位置**: `altair/vegalite/v6/api.py:2124-2125`

```python
if func := theme.get():
    # 关键：update_nested 的参数顺序！
    vegalite_spec = utils.update_nested(func(), vegalite_spec, copy=True)
```

这行代码决定了主题合并的优先级。

### 3.2 `update_nested` 函数详解

**位置**: `altair/utils/core.py:807-849`

```python
def update_nested(
    original: Any,           # 第一个参数：被更新的对象
    update: Mapping[Any, Any],  # 第二个参数：用来更新的对象
    copy: bool = False,
) -> MutableMapping[Any, Any]:
    """
    嵌套更新字典
    
    参数顺序决定优先级：
    - original: 原始值（会被 update 覆盖）
    - update: 更新值（优先级更高）
    """
    if copy:
        original = deepcopy(original)
    
    for key, val in update.items():
        if isinstance(val, Mapping):
            orig_val = original.get(key, {})
            if isinstance(orig_val, MutableMapping):
                # 递归合并子字典
                original[key] = update_nested(orig_val, val)
            else:
                # 非字典类型，直接覆盖
                original[key] = val
        else:
            # 叶子节点，直接覆盖
            original[key] = val
    
    return original
```

#### 参数顺序决定优先级

```python
update_nested(主题配置, 图表配置, copy=True)
              ↑              ↑
            original        update
              ↓              ↓
           低优先级        高优先级
```

**结论**：**图表配置会覆盖主题配置中的相同键**！

## 4. 跨类插件：主题 vs 渲染器的 embedOptions 优先级

### 4.1 两条独立的传递路径

#### 路径 A：主题的 `usermeta.embedOptions`

**流向**：
```
VegaTheme.__call__()
    ↓
返回 {"usermeta": {"embedOptions": {"theme": "quartz"}}, ...}
    ↓
update_nested(主题配置, 图表配置)
    ↓
合并到 spec.usermeta.embedOptions
    ↓
传递给 vegaEmbed(spec, embedOpt) 作为 spec 的一部分
```

**代码证据**：

**位置**: `altair/vegalite/v6/theme.py:86-90`

```python
def __call__(self) -> ThemeConfig:
    return {
        "usermeta": {"embedOptions": {"theme": self.theme}},  # 路径 A
        "config": {"view": {"continuousWidth": 300, "continuousHeight": 300}},
    }
```

#### 路径 B：渲染器的 `embed_options`

**流向**：
```
RendererRegistry.set_embed_options(actions=True, ...)
    ↓
调用 enable(None, embed_options={...})
    ↓
存储在 renderers._options["embed_options"]
    ↓
spec_to_mimebundle() 中读取 renderers.options.get("embed_options", {})
    ↓
传递给 spec_to_html(embed_options=...)
    ↓
传递给 jinja 模板的 embed_options 变量
    ↓
在 JavaScript 中作为 embedOpt 传递给 vegaEmbed(spec, embedOpt)
```

**代码证据**：

**位置 1**: `altair/utils/display.py:104-116`

```python
def set_embed_options(self, ...) -> PluginEnabler:
    options: dict[str, ...] = {
        "defaultStyle": defaultStyle,
        "renderer": renderer,
        "width": width,
        "height": height,
        # ...
    }
    kwargs.update({key: val for key, val in options.items() if val is not None})
    
    # 关键：作为 embed_options 传递给 enable
    return self.enable(None, embed_options=kwargs)
```

**位置 2**: `altair/utils/mimebundle.py:127-133`

```python
def spec_to_mimebundle(...):
    # ...
    
    # 从渲染器选项中读取 embed_options
    if embed_options is None:
        final_embed_options = renderers.options.get("embed_options", {})
    else:
        final_embed_options = embed_options
    
    embed_options = preprocess_embed_options(final_embed_options)
    
    # ... 传递给 spec_to_html
```

**位置 3**: `altair/utils/html.py:399-401`

```python
return jinja_template.render(
    spec=json.dumps(spec, **json_kwds),           # 包含 usermeta.embedOptions
    embed_options=json.dumps(embed_options),     # 路径 B 的 embed_options
    # ...
)
```

**位置 4**: HTML 模板（以 `HTML_TEMPLATE` 为例）

```javascript
vegaEmbed("#{{ output_div }}", spec, embedOpt)
//                        ↑        ↑
//                   路径 A    路径 B
//              (包含 usermeta)  (单独参数)
```

### 4.2 vega-embed 中的优先级

根据 [vega-embed 文档](https://github.com/vega/vega-embed) 和源码分析，`vegaEmbed(spec, opt)` 的行为是：

1. **首先**从 `spec.usermeta.embedOptions` 读取默认选项
2. **然后**用传入的 `opt` 参数**合并/覆盖**

**优先级**：`opt`（路径 B）> `spec.usermeta.embedOptions`（路径 A）

### 4.3 优先级演示

```python
import altair as alt

# 场景：启用一个 Vega 主题，同时设置渲染器选项

# 路径 A：主题设置 embedOptions.theme = "quartz"
alt.theme.enable("quartz")
# 这会在 spec 中设置:
# spec.usermeta.embedOptions = {"theme": "quartz"}

# 路径 B：渲染器设置 embedOptions.actions = False
alt.renderers.set_embed_options(actions=False)
# 这会设置:
# renderers._options = {"embed_options": {"actions": False}}

# 最终传递给 vegaEmbed:
# vegaEmbed(spec, {"actions": False})
#
# spec.usermeta.embedOptions = {"theme": "quartz"}
# opt = {"actions": False}
#
# 合并后:
# embedOptions = {"theme": "quartz", "actions": False}
# （如果有冲突，opt 覆盖 spec.usermeta）
```

### 4.4 冲突场景演示

```python
import altair as alt

# 场景：两者设置了同一个选项

# 路径 A：主题设置 theme = "quartz"
alt.theme.enable("quartz")
# spec.usermeta.embedOptions = {"theme": "quartz"}

# 路径 B：渲染器也设置 theme = "dark"
alt.renderers.set_embed_options(theme="dark")
# renderers._options = {"embed_options": {"theme": "dark"}}

# 最终：
# vegaEmbed(spec, {"theme": "dark"})
#
# 由于 opt.theme = "dark" 覆盖 spec.usermeta.embedOptions.theme
# 实际使用的主题是 "dark"，不是 "quartz"！
```

**结论**：**渲染器的 `embed_options` 优先级高于主题的 `usermeta.embedOptions`**。

## 5. 关键冲突场景的代码证据

### 5.1 场景 1：同类插件多次 `enable()` 覆盖

**代码证据**：`altair/utils/plugin_registry.py:220-221`

```python
# _enable 方法中
self._active_name = name    # 直接赋值，无检查
self._active = self._plugins[name]  # 直接覆盖
```

### 5.4 场景 4：显式注册覆盖入口点

```python
def _enable(self, name: str, **options) -> None:
    # 关键检查：只有 _plugins 中不存在时，才查入口点
    if name not in self._plugins:

            (ep,) = (ep for ep in importlib_metadata_get(self.entry_point_group) 
                     if ep.name == name)
        except ValueError:
            raise NoSuchEntryPoint(...)

    self._active = self._plugins[name]
```

- 因此**显式注册优先**
